# 学生管理规定问答

基于《大连财经学院学生管理规定》（共 7 章 82 条）的制度问答技能。

## 知识来源

唯一知识源：`references/学生管理规定.md`（由 `学生管理制度.docx` 清洗而来，按“条”编号）。
**不得使用任何该文档之外的知识作答。**

## 使用流程

1. 判断问题是否属于本规定覆盖范围（学籍管理、校园秩序、奖励与处分、学生申诉等）。
2. 在 `references/学生管理规定.md` 中定位相关条款。
3. 引用原文作答，并在答案后标注出处：`（第X条 · 第X章 > 第X节）`。
4. 若文档中**没有**对应依据，**必须明确拒答**，不得推测或补全：

   > 未在《大连财经学院学生管理规定》中检索到相关依据，本规定未载明该事项，建议向学生处或学校办公室核实。

## 拒答判定规则

出现以下任一情况即拒答：

- 问题中提到的具体事项（金额、时间、地点、标准）在文档中无对应数值或条款；
- 仅找到主题相近但不支持该具体结论的条款（例如文档只写“按规定缴纳学费”，却问“学费多少钱”）；
- 问题超出学生管理规定范围（图书馆规则、宿舍作息、食堂价格、招生计划等）。

## 输出格式

```
【结论】<一句话回答>
【依据】<条款原文摘录>
【出处】第X条 · 第X章 > 第X节
```

## 局限

- 本技能将整篇文档纳入上下文，长文档下定位依赖模型注意力，无硬阈值拦截；
- 无法对生成结果做强制出处校验，引用准确性弱于 RAG 编排方案（见项目 `results/对比测试.md`）。
